## Reporting a Vulnerability

We take the security of GefenStarlight seriously. If you believe you have discovered a security vulnerability in this project, please report it to us responsibly.

### How to Submit a Security Report
- **Email**: Send details of the vulnerability to `security@gefenstarlight.local` (or project maintainers directly).
- **Do NOT open a public GitHub issue** for security vulnerabilities.

### What to Include in your Report
1. A clear description of the vulnerability and potential impact.
2. Step-by-step instructions or proof-of-concept script to reproduce the issue.
3. Any suggested remediations or mitigations if available.

### Response Timeline
- **Acknowledgement**: Within 48 hours of report receipt.
- **Assessment & Status Update**: Within 7 business days.
- **Fix & Public Disclosure**: Target release of patch within 30 days depending on severity.

Thank you for helping keep GefenStarlight safe for everyone!
